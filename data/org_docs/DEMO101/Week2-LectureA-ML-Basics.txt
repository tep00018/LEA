# Week 2: Machine Learning Basics

## What is Machine Learning?

Machine Learning is a method of data analysis that automates analytical model building. It uses algorithms that iteratively learn from data, allowing computers to find hidden insights without being explicitly programmed.

## Types of Machine Learning

### Supervised Learning
The algorithm learns from labeled training data. Given input-output pairs, it learns to predict outputs for new inputs.

**Examples:**
- Email spam detection (labeled as spam/not spam)
- House price prediction (given features like size, location)
- Image classification (cat vs dog)

### Unsupervised Learning
The algorithm finds patterns in unlabeled data without predefined categories.

**Examples:**
- Customer segmentation
- Anomaly detection
- Dimensionality reduction

### Reinforcement Learning
The algorithm learns through trial and error, receiving rewards or penalties for actions.

**Examples:**
- Game playing (chess, Go)
- Robotics
- Self-driving cars

## Common ML Algorithms

1. **Linear Regression**: Predicting continuous values
2. **Logistic Regression**: Binary classification
3. **Decision Trees**: Classification and regression
4. **K-Means Clustering**: Grouping similar data points
5. **Neural Networks**: Complex pattern recognition
